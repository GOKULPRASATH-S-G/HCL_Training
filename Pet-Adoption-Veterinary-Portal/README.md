# Pet Adoption & Veterinary Clinic Portal

## Project Overview

The Pet Adoption & Veterinary Clinic Portal is a web-based application designed to manage pet adoption activities and veterinary clinic services in one platform.

The system helps shelter staff manage pets and adoption applications, allows adopters to apply for pets, and provides veterinary appointment and medical record management.

## Objectives

- Manage registered pets and their adoption status.
- Allow adopters to search and apply for pets.
- Manage adoption applications and home visits.
- Approve adoptions and update pet status.
- Allow pet owners to book veterinary appointments.
- Maintain veterinary visit and vaccination records.
- Send vaccination reminders.
- Provide adoption statistics for administrators.

## User Roles

### Admin
- View adoption statistics.
- Monitor adoption activities.

### Shelter Staff
- Manage pet listings.
- Review adoption applications.
- Schedule home visits.
- Approve adoptions.
- Update pet adoption status.

### Veterinarian
- Manage veterinary visit records.
- Add medical notes.
- Record vaccinations.

### Adopter / Pet Owner
- Search and filter available pets.
- Submit adoption applications.
- Book veterinary appointments.
- Receive vaccination reminders.
