# Definition of Done

A user story is considered **Done** when all of the following conditions are satisfied:

1.The requirement is clearly understood.
2.Acceptance criteria are defined and satisfied.
3.The required functionality is implemented.
4.Input validation is implemented where required.
5.Business rules are implemented correctly.
6.Unit tests are written and passing.
7.Integration/API testing is completed where applicable.
8.No critical or high-priority defects remain.
9.Code review is completed.
10.Database changes are completed and verified where required.
