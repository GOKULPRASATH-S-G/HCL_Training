# HCL Training – Day 3

## Module
Control Flow + Console Input Processing

## Java Task
### ATM Simulator

The ATM Simulator demonstrates Java control flow mechanisms and interactive console input handling by modeling a secure PIN verification terminal.

### Concepts Demonstrated
- Console input reading using `Scanner`
- Defensive input validation using `hasNextInt()` to handle invalid user input
- While loops for repeated authentication attempts
- Conditional branching using `if` and `else` statements
- Loop control statements (`break` on successful authentication, `continue` on format error)
- Program termination using `return`
- Bounded retry limits and account lockout logic
- Defining security constants using `final` (`CORRECT_PIN`, `MAX_ATTEMPTS`)
- Attempt tracking and status flag management

### Build & Tooling Fundamentals
- Introduction to Apache Maven build automation
- Maven project structure and configuration using `pom.xml`
- Source and target compilation configuration for Java 21

## Project Task
### Pet Adoption & Veterinary Clinic Portal

The project task applies control flow constructs and input validation to build interactive, menu-driven console navigation for shelter staff, veterinarians, and adopters.
