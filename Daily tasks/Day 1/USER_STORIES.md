# Pet Adoption & Veterinary Clinic Portal

## User Stories

### US01 — List Pets

**Functional Requirement:** FR1

**User Story:**

> As a Shelter Staff member, I want to list registered pets with their current adoption status so that I can manage and monitor pets available for adoption.

**Story Points:** 3

**Acceptance Criteria:**
- Staff can view registered pets.
- Each pet displays its name, type/breed and adoption status.
- Staff can distinguish available, pending and adopted pets.

---

### US02 — Filter Pets and Apply for Adoption

**Functional Requirement:** FR2

**User Story:**

> As an Adopter, I want to filter available pets and submit an adoption application so that I can find a suitable pet and request adoption.

**Story Points:** 5

**Acceptance Criteria:**
- Adopter can filter available pets.
- Adopter can view pet details.
- Adopter can submit an adoption application.
- Application is stored successfully.
- Adopter receives confirmation after submission.

---

### US03 — Review Applications and Schedule Home Visits

**Functional Requirement:** FR3

**User Story:**

> As a Shelter Staff member, I want to review adoption applications and schedule home visits so that I can evaluate potential adopters before approval.

**Story Points:** 5

**Acceptance Criteria:**
- Staff can view submitted applications.
- Staff can review adopter information.
- Staff can schedule a home visit.
- Application status is updated after review.

---

### US04 — Approve Adoption and Update Pet Status

**Functional Requirement:** FR4

**User Story:**

> As a Shelter Staff member, I want to approve an adoption and update the pet's status so that the system accurately reflects the pet's adoption state.

**Story Points:** 3

**Acceptance Criteria:**
- Staff can approve an eligible adoption application.
- Pet status changes to ADOPTED.
- Approved application is recorded.
- Adopted pets no longer appear as available.

---

### US05 — Book Veterinary Appointment

**Functional Requirement:** FR5

**User Story:**

> As a Pet Owner, I want to book a veterinary appointment so that my pet can receive medical care at a suitable time.

**Story Points:** 5

**Acceptance Criteria:**
- Pet owner can select a pet.
- Pet owner can select an available date and time.
- Appointment is created successfully.
- The system prevents double booking.

---

### US06 — Record Veterinary Visit and Vaccination

**Functional Requirement:** FR6

**User Story:**

> As a Veterinarian, I want to record visit notes and vaccination details so that the pet's medical history is maintained accurately.

**Story Points:** 5

**Acceptance Criteria:**
- Veterinarian can access the pet's medical record.
- Veterinarian can add visit notes.
- Veterinarian can record vaccination details.
- Updated medical information is stored successfully.

---

### US07 — Send Vaccination Reminders

**Functional Requirement:** FR7

**User Story:**

> As a Pet Owner, I want to receive vaccination reminders so that I do not miss my pet's required vaccinations.

**Story Points:** 5

**Acceptance Criteria:**
- System identifies upcoming vaccinations.
- System generates a reminder for the pet owner.
- Reminder contains pet and vaccination information.
- The same reminder is not repeatedly sent for the same vaccination event.

---

### US08 — View Adoption Statistics

**Functional Requirement:** FR8

**User Story:**

> As an Admin, I want to view adoption statistics so that I can monitor adoption activity and make informed decisions.

**Story Points:** 3

**Acceptance Criteria:**
- Admin can access adoption statistics.
- Statistics include adoption counts.
- Admin can view adoption trends/status.
- Only authorized administrators can access the statistics.
