# HCL Training – Day 4

## Module
Object-Oriented Programming (OOP) Fundamentals + Encapsulation

## Java Task
### Bank Account Management System

The Bank Account system demonstrates the core principles of Object-Oriented Programming in Java by modeling financial account transactions with strict state encapsulation.

### Concepts Demonstrated
- Encapsulation using `private` fields to protect internal account state
- Domain methods with guard clauses for deposit and withdrawal operations
- Validation rules to prevent negative transaction values and overdrafts
- Constructor overloading to support multiple initialization scenarios
- Constructor chaining using `this(...)` to eliminate code duplication
- Static variables to track shared class-level state (total account counter)
- Static methods to access class-level data without instance creation
- Overriding the `equals()` method for logical value equality based on account numbers
- Overriding the `hashCode()` method in agreement with the `equals()` contract

### Debugging Fundamentals
- Using IDE debugging tools to inspect running Java applications
- Setting line breakpoints to pause program execution
- Stepping through methods (Step Over, Step Into, Step Out)
- Inspecting call stacks, local variables, and object references in memory
