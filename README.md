# HCL Training

This repository contains my work and practice tasks completed during my HCL training.

The repository is mainly used to keep track of the concepts I learn, daily tasks I complete, and the project work developed during the training.

### Daily Tasks

The `Daily tasks` folder contains the programming exercises and assignments completed as part of the training.

These tasks cover the concepts discussed during the sessions and are added regularly as the training progresses.

### Project

The `Project` folder contains the main project developed during the training. It includes the source code and related files used while building and improving the application.

## Technologies

The technologies used in this repository depend on the particular task or project. The training work mainly focuses on:

- Java
- Core Java
- Object-Oriented Programming
- Maven
- Spring Boot
- REST APIs
- Microservices
- Spring Cloud
- Eureka Service Discovery
- Git & GitHub

## Purpose

The main purpose of this repository is to:

- Practice concepts learned during HCL training
- Maintain my daily coding tasks in one place
- Track my progress throughout the training
- Develop and maintain the training project
- Keep the code organized for future reference


## Progress

This repository will be updated throughout the HCL training with new daily tasks, improvements, and project development work.
